# irbis-frontend

React-клиент к [irbis-api](../irbis-api): вход по кукам, поиск с фильтрами, сборка инвентарной книги.

## Запуск

```bash
# терминал 1 — API
cd ../irbis-api && cp -n .env.example .env && go run ./cmd/server

# терминал 2 — фронт
cd ../irbis-frontend && npm install && npm run dev
```

Откройте http://localhost:5173  
В `.env` API добавьте `CORS_ALLOW_ORIGIN=http://localhost:5173` (на случай прямых запросов). В dev Vite проксирует `/v1` на `:8080`.

## Возможности

- Вход / выход (меню пользователя справа вверху)
- Страница **Поиск**: выбор базы, несколько фильтров (поле Ирбис + значение, в т.ч. сырое выражение), Enter или кнопка «Поиск»
- Галочки у результатов → панель справа → **Собрать** → таблица инвентарной книги с выбором полей/подполей
- Ошибки API — всплывающие уведомления с закрытием
